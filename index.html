Backup e dados

Como salvar no OneDrive (primeira vez)
  1. Toque em Exportar backup.
  2. No menu Compartilhar, escolha Salvar em Arquivos.
  3. Toque em Procurar e escolha OneDrive (se não aparecer: Procurar → ⋯ → Editar e ative o OneDrive; é preciso ter o app OneDrive instalado e conectado).
  4. Crie uma pasta, por exemplo Backups Glicemia, e toque em Salvar.

Nas próximas vezes o iPhone já abre na última pasta usada: é só tocar em Salvar. Um arquivo por dia (ex.: backup-glicemia-2026-11-15.json); se salvar de novo no mesmo dia, escolha Substituir. O arquivo contém os dados das duas pessoas.

Mais opções

“Restaurar backup” mescla: só preenche o que está vazio no aparelho e nunca apaga registros. “Substituir tudo” troca todos os dados pelos do arquivo. Antes de qualquer restauração, uma cópia de segurança dos dados atuais é guardada para permitir desfazer.

Privacidade: os registros ficam armazenados neste aparelho, neste navegador. Não há conta nem envio de dados para servidor. Exporte backups regularmente — se os dados do site forem apagados, só o backup os recupera.

Atenção: os destaques (≥180 mg/dL e diferença >30 mg/dL entre antes e 2h após a refeição) são critérios de organização configurados por você. Não representam diagnóstico nem substituem orientações do profissional de saúde.
